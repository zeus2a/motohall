#  CE SITE N'A RIEN A FAIRE DANS UN MOTEUR DE RECHERCHE.
#  C'est l'intranet d'une concession : un outil de travail pour le
#  personnel, pas une vitrine. Un robot qui l'indexerait ferait apparaitre
#  dans Google des adresses internes (« /dashboard.php », « /login.php »),
#  et attirerait du passage sur une porte qui ne leur est pas destinee.
#
#  CE FICHIER N'EST QU'UN VERROU PARMI TROIS, ET C'EST VOULU :
#    1. ce fichier            — pour les robots qui le respectent ;
#    2. l'en-tete X-Robots-Tag — dans .htaccess, pour TOUTES les reponses,
#                                y compris les fichiers non HTML ;
#    3. <meta name="robots">   — dans les pages (voir les gabarits).
#  Un robot mal eleve ignore le premier ; les deux autres le rattrapent.
# =====================================================================
